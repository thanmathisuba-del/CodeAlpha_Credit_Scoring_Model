# 💳 Credit Scoring Model

## CodeAlpha Machine Learning Internship

### 📌 Project Overview

This project predicts an individual's creditworthiness using past financial data and machine learning classification algorithms.

The model classifies applicants into:

- Good Credit
- Bad Credit

## 🎯 Objective

To develop a machine learning model that can predict creditworthiness based on financial information.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab
- GitHub

## 🤖 Machine Learning Models

Two classification algorithms were implemented:

1. Logistic Regression
2. Random Forest Classifier

## 📊 Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

## 📈 Results

| Model | Accuracy | Precision | Recall | F1-Score | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 70.5% | 77.55% | 81.43% | 79.44% | 75.94% |
| Random Forest | 76.0% | 79.87% | 87.86% | 83.67% | 77.99% |

## 🏆 Best Model

Random Forest achieved better overall performance compared with Logistic Regression.

The Random Forest model achieved:

- Accuracy: 76.0%
- Precision: 79.87%
- Recall: 87.86%
- F1-Score: 83.67%
- ROC-AUC: 77.99%

## 🔮 Sample Prediction

The trained Random Forest model successfully predicted a sample applicant as:

**Good Credit**
